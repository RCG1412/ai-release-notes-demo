# Release Notes - Version 2.4.0

## Release Highlights

- **Dark Mode UI** — Reduce eye strain with a beautiful dark theme. Toggle it anytime in your preferences to match your environment.
- **Webhook Retry Mechanism** — Enjoy uninterrupted integrations with automatic retry logic that ensures your webhooks always go through, even during temporary failures.
- **Bulk CSV Export** — Stream large datasets to CSV without timeout worries. Perfect for comprehensive data backups and analysis.
- **Audit Log Viewer** — Track every action in your account with a searchable audit trail, giving you complete visibility into user activity and changes.
- **Order Summary Enhancements** — View complete order details including tracking numbers, delivery estimates, and payment information all in one place.
- **Dashboard Speed Improvements** — Experience faster dashboard load times with optimized query performance, so your metrics load instantly.
- **API Rate Limit Boost** — Standard tier users now get 5x higher rate limits (500 req/min) for more powerful integrations and workflows.
- **User Profile Customization** — Personalize your experience with timezone selection, language preferences, and notification sound settings.

## New Features

### Dark Mode UI
Switch to a dark-themed interface with just one click. All interface elements are styled for comfortable viewing in low-light environments. Access the toggle in your user preferences.

### Webhook Retry Mechanism
Failed webhook deliveries are automatically retried up to 5 times with intelligent backoff. Your integrations stay reliable even when temporary network issues occur.

### Bulk CSV Export
Export large datasets directly to CSV format using a dedicated streaming endpoint. Pagination ensures you won't run into memory limits, no matter how much data you export.

### Audit Log Viewer
A comprehensive, searchable audit trail that logs every user action with exact timestamps. Use filters to drill down into specific activities and export logs for compliance purposes.

### User Profile Screen - Enhanced Fields

| Field | Description |
|-------|-------------|

| Language Preference | Choose interface language from 12 supported options |
| Notification Sound | Pick from 5 alert sounds or disable completely |

## Enhancements

### Dashboard Load Time Optimization
Dashboard widgets now load significantly faster thanks to intelligent caching. Your metrics appear instantly without the delay.

### Global Search Indexing Upgrade
Search results are now faster and more accurate. The search engine has been upgraded to handle fuzzy matching more efficiently, getting you to what you need in milliseconds.

### Increase API Rate Limits
Standard tier API rate limits have been increased from 100 to 500 requests per minute, enabling more powerful integrations and high-volume workflows.

## Bug Fixes

- **Login Page Null Pointer Exception** — Fixed a crash that occurred when using OAuth with an empty email field. Login now works reliably.
- **Dashboard Widget Data Mismatch** — Corrected a timezone conversion bug that was displaying yesterday's metrics instead of today's data.
- **CSV Export Encoding Error** — Fixed UTF-8 encoding issue that caused special characters to display incorrectly when opening exported files in Excel.
- **Search Results Pagination Broken** — Resolved an off-by-one error that was skipping results on page 2 and beyond. Pagination now works correctly.
- **Webhook Payload Missing Timestamp** — Restored the ISO 8601 timestamp field to webhook payloads that was accidentally removed in the previous version.
